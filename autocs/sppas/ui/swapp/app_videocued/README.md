# app_videocued -- unfinished, kept on purpose

**Do not read this directory, and do not repair it.**

This app was left unfinished. What was written is correct, and it is kept as
it is until an app answering the same need is written. Reading it costs time
and tells nothing about the current swapp: it does not describe how swapp
works today.

Nothing reaches it at run time: it is not listed in `WEB_APPLICATIONS`, it is
not under `spinoff/`, and the discovery of the spin-offs never walks this
directory. It cannot break anything.

Its relative imports -- `..components`, `..htmltags`, `..apps.swapp_bakery`,
`..swappsg` -- name modules of an earlier organization of swapp. They are dead
imports, and they are expected to be. They are not a bug to fix.

Renaming passes over swapp are applied here too, so that the directory stays
spelled like the rest of the package. Nothing else is done to it.
